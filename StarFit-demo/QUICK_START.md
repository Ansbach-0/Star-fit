# 🚀 Quick Start Guide - StarFit

## Get Running in 2 Minutes!

### Step 1: Start Backend (Terminal 1)
```bash
cd e:\Git\Star-fit\StarFit-demo\auth-backend
node server.js
```
✅ **Backend ready on http://localhost:4000**

### Step 2: Start Frontend (Terminal 2)
```bash
cd e:\Git\Star-fit\StarFit-demo\starfit-vite
npm run dev
```
✅ **Frontend ready on http://localhost:5173**

### Step 3: Login & Test

#### Option A: Test as Manager
1. Go to http://localhost:5173
2. Click **"Login"**
3. Login with:
   - Email: `manager@starfit.com`
   - Password: `admin123`
4. ✨ **You'll see**: Dashboard with analytics, member list, and routine creation

#### Option B: Test as User
1. Go to http://localhost:5173
2. Click **"Login"**
3. Login with:
   - Email: `user@starfit.com`
   - Password: `user123`
4. ✨ **You'll see**: Personal dashboard with your routines and plan details

## 🎯 What to Test

### As Manager:
1. ✅ View dashboard statistics (revenue, members, occupancy)
2. ✅ See member list in table
3. ✅ Click "Criar Rotina" for any user
4. ✅ Select exercise from dropdown
5. ✅ Set sets/reps and create routine

### As User:
1. ✅ View "Minhas Rotinas" (assigned exercises)
2. ✅ Click "Concluir Exercício" to complete
3. ✅ Browse "Exercícios Disponíveis"
4. ✅ Check "Meu Plano" for subscription info
